# 🎲 Quiz Factory

> **一句话生成一个可以分享的人格测试**：8 道题 · 2 分钟 · 8 种结果 · 单文件网页。
> 输入「测测你是哪种小猫」→ 输出一个点开就能测、测完能分享结果链接的 HTML 页面。

```text
你：测测你是哪种打工人
↓（三段式生成：类型名 → 题目 → 文案，每段带质量门禁，5-12 分钟 / 云端更快）
3 条轴 × 8 道题 × 8 种结果 + 打分逻辑 + 页面（全部内联成 1 个 HTML）
↓
docs/index.html   ← 测试库；每个测试都是独立 HTML，能直接发人 / 挂 GitHub Pages
```

---

## 3 分钟体验（不需要模型）

直接双击打开 **`docs/index.html`**，里面有 5 个测试：

| 测试 | 来源 | 说明 |
|---|---|---|
| 🐱 测测你是哪种小猫 | 人工精写 | 最典型的"轻娱乐"场景，验证产品形态 |
| 🧠 测测你是哪种 AI 产品经理 | 人工精写 | 主题和求职方向一致，作品集入口 |
| 📚 测测你是哪种文献阅读人格 | AI 生成 + 人工润色 | 7B 三段式生成，润色内容见 examples/README.md |
| ✏️ 测测你的期末复习风格：卷王还是躺平侠 | AI 生成 + 人工润色 | **三段全部一次通过门禁**的样例 |
| 🏖️ 测测你的假期旅行人格 | AI 生成 + 人工润色 | 同上 |

点进去答题 → 出结果页 → 「分享结果」会带上 `#r=类型` 的深链，朋友点开直接看到你的结果。
所有测试的 8 种结果占比都经过穷举校准（实测 9.8%–15.6%，见 tests）。

## 生成你自己的测试

```bash
# 命令行（本地 Ollama，默认 qwen2.5:7b）
python generate.py --theme "测测你是哪种咖啡" --slug coffee

# 云端模型（更快更准，key 放环境变量 QUIZ_API_KEY 或 .env 的 LIT_API_KEY）
python generate.py --theme "测测你是哪种咖啡" --slug coffee --provider openai --model deepseek-chat

# 网页版（推荐）：主题 → 三段进度 → 门禁报告 → 下载/试玩
python -m streamlit run app.py
```

生成完自动出现在 `docs/index.html` 和 `docs/quizzes.json` 里；
每次生成的门禁报告（各段尝试次数、问题清单、结果分布）保存在 `quizzes/<slug>.report.json`。

## 工作原理（v2：三段式生成 + 结构化公平）

| 步骤 | 做什么 | 为什么这样做 |
|---|---|---|
| 1. 骨架 | 模型只出 3 条轴 + 8 个类型名/emoji/标签 | 输出短，类型名重复率大幅下降 |
| 2. 题目 | **每题只考 1 条轴**：正/负/中性三个选项，每轴至少 2 题 | 公平性由**结构保证**，不靠模型自觉（v1 实测 7B 做不到轴平衡） |
| 3. 文案 | 逐个类型写描述/高光/小毛病/合拍，**输入含每个 key 的轴语义** | 消除"文案与类型错位"；短输出质量高 |
| 4. 门禁 | 每段独立校验（名称唯一/单个 emoji/无占位符/结构合法），不合格带反馈重试（最多 3 次） | 模型犯错只重做那一段；报告如实记录 |
| 5. 打分 | 结果 = 3 条轴符号拼成 3 位 key，**代码算不让模型猜** | 100% 可复现 |
| 6. 校准 | 穷举所有作答，给每条轴找"刚好劈成两半"的阈值 | 消除"某类型占 40%"；实测分布 9.8%–15.6% |
| 7. 渲染 | 题目/结果/样式/分享/稀有度全部内联进单个 HTML | 零后端、零成本、可离线、微信里点开就能测 |

生成质量的真实数据（v1 → v2 的四步改进，含失败记录）见 **[examples/README.md](examples/README.md)**。

## 目录结构

```text
quiz_factory/
├── generate.py        # 三段式生成管线 + 门禁 + 渲染/建索引（命令行）
├── app.py             # Streamlit 网页版：生成进度 / 门禁报告 / 测试库下载
├── model.py           # 数据模型、校验、质量门禁、阈值校准、稀有度
├── render.py          # 单文件 HTML 模板（封面/答题/结果/测试库）
├── llm.py             # LLM 客户端：本地 Ollama + OpenAI 兼容云端（DeepSeek 等）
├── presets/           # 人工精写的预设测试
├── quizzes/           # 生成的测试数据 + 门禁报告（*.report.json）
├── docs/              # 最终产物：测试库 index.html + 每个测试的 HTML（GitHub Pages 目录）
└── examples/          # 生成器的真实水平：各版本原始输出 + 诚实记录
```

## 质量检查

```bash
python tests/test_reachable.py    # 8 种结果全部可达，分布均衡
python tests/test_render.py       # HTML 无占位符、8 种结果齐全、无外部资源
python tests/test_generated.py    # 所有预设 + 生成数据统一体检
```

- 生成的 HTML **不引用任何外部资源**，断网也能打开；
- 逻辑是"累加分值 → 符号 → 查结果表"，不依赖模型，100% 可复现；
- 数据渲染前会过完整校验；生成阶段每段有独立质量门禁与自动重试。

## 发布到 GitHub Pages

`docs/` 就是为 Pages 准备的目录：仓库 Settings → Pages → Branch `main` + 目录 **/docs** 即可，
无需构建。单文件特性也意味着：把 `docs/<slug>.html` 一个文件发给朋友，微信里点开就能测。

## 已知边界

- 这是**娱乐性人格测试**，不是心理测量工具，结果不具备心理学效度；
- 生成版定位「AI 初稿 + 人工润色」：结构、平衡、占位符等由门禁保证，
  **文案的品味和得体性发布前必须人工过一遍**（真实修改记录见 examples/README.md）；
- 本地 7B 一次生成约 5-12 分钟；云端 API 快且质量更高，但有成本。
